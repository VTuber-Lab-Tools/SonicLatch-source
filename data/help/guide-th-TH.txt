SonicLatch — วิธีใช้การปรับความหน่วงเสียง

สภาพแวดล้อมและการติดตั้ง

เป้าหมายคือ Windows 64 บิตและ OBS 30 ขึ้นไป (แนะนำ OBS 32.2.2) ยืนยันการโหลดและการแสดงด็อกบน OBS 32.2.2 ในเครื่องจริงแล้ว ส่วน OBS 30/31 ยังไม่ได้ทดสอบบนเครื่องจริง ปิด OBS ก่อนติดตั้ง และใช้คำแนะนำการติดตั้งและถอนการติดตั้งภาษาญี่ปุ่นหรืออังกฤษที่แนบมา

วัด ตรวจสอบ และปรับ

1. เลือกแหล่งเสียงและป้อนสัญญาณเสียง ฟิลเตอร์วัด “การวัดความหน่วงเสียง (SonicLatch)” จะถูกเพิ่มโดยอัตโนมัติ ไม่ต้องเพิ่มเอง และอย่าปิด ลบ หรือเปลี่ยนลำดับระหว่างใช้งาน การเปลี่ยนออฟเซ็ตจะมีผลกับทุกฉากที่ใช้แหล่งเสียงนี้

2. ตรวจสอบรูปคลื่น PRE (ก่อนประมวลผล), POST (หลังประมวลผล), ความหน่วง D และ การวัด เครื่องหมาย “—” หมายถึงไม่มีค่า ไม่ใช่ศูนย์ ความเงียบ การปิดเสียง ความเชื่อมั่นต่ำ หรือการวัดที่เก่าหรือไม่ถูกต้องอาจทำให้ปรับไม่ได้ ตรวจสอบสัญญาณและรอค่าประมาณใหม่ที่ใช้ได้

3. เมื่อมีค่าประมาณที่ใช้ได้ ให้ใช้ ปรับอัตโนมัติ (Auto) ซึ่งจะตั้งออฟเซ็ตสัมบูรณ์ S เป็น −D ไม่ใช่ลบ D จากออฟเซ็ตเดิม หาก D = +80 ms เป้าหมายคือ −80 ms การวัดและแสดงผลอย่างเดียวไม่เปลี่ยนออฟเซ็ต

4. ปรับละเอียดด้วย −5 ms, −1 ms, +1 ms, +5 ms หรือป้อนตัวเลขแล้วใช้ ใช้ออฟเซ็ตที่ป้อน การพิมพ์อย่างเดียวไม่บันทึกค่า เลิกทำ คืนค่าก่อนการทำงานที่สำเร็จครั้งล่าสุดหากยังใช้ได้ ส่วน รีเซ็ตออฟเซ็ต ตั้งเป็น 0 ms ไม่ใช่ค่าเริ่มต้นเดิม

5. ตรวจสอบการบันทึกหรือการถ่ายทอดสดจริง สภาพแวดล้อมและภาระประมวลผลอาจทำให้เสียงไม่ตรงกันอย่างสมบูรณ์ ค่าและความหน่วงอาจเปลี่ยนหลังตั้งค่าหรือระหว่างถ่ายทอดสด หากเสียงคลาดเคลื่อน ให้รอค่าประมาณปัจจุบันที่ใช้ได้แล้วใช้ Auto อีกครั้ง Auto เป็นการสั่งปรับใหม่ ไม่ใช่การติดตามต่อเนื่องหรือการรับรองว่าเสียงจะตรงกันสมบูรณ์

ความหมายของการแสดงผล

D เป็นค่าประมาณจากการเปรียบเทียบ PRE กับ POST ส่วน S คือออฟเซ็ตการซิงค์ของ OBS (ออฟเซ็ตปัจจุบัน O) และ ค่าคงเหลือปัจจุบัน คือ D + S ตำแหน่ง POST ที่แสดงรวม S แล้ว แต่ตำแหน่งและค่าคงเหลือนี้เป็นค่าประมาณจากแบบจำลอง ไม่ใช่การวัดเอาต์พุตหลังแก้ไขใหม่ การอ่านกลับที่ตรงกันยืนยันเฉพาะค่าที่บันทึกใน OBS ไม่ได้ยืนยันว่าเสียงในไฟล์บันทึกตรงกัน

ช่วงค่าและการแก้ปัญหา

เสียงสเตอริโอ 44.1 kHz หรือ 48 kHz ช่วงวัดความหน่วงอยู่ประมาณภายใน ±500 ms โดยไม่รวมปลายช่วงค้นหา ส่วนช่วงเขียนออฟเซ็ตคือ −950 ถึง +1000 ms ซึ่งเป็นคนละช่วง การเปลี่ยนแหล่งเสียงหรือออฟเซ็ตจากภายนอกอาจทำให้คำแนะนำและการเลิกทำใช้ไม่ได้ อ่านออฟเซ็ตปัจจุบัน อ่านค่าเท่านั้นและไม่คืนความสามารถในการเลิกทำ หากยังยืนยันการเขียนหรืออ่านกลับไม่ได้ อย่าถือว่าสำเร็จหรือคลิกซ้ำ ให้ตรวจสอบสถานะ แหล่งเสียง และคุณสมบัติเสียงขั้นสูงของ OBS

ภาษาและการสนับสนุน

ส่วนติดต่อและคู่มือครอบคลุม 16 โลแคลเดียวกัน รองรับการสอบถามเป็นภาษาญี่ปุ่นและอังกฤษ ไม่ได้สัญญาว่าจะมีการสนับสนุนหรือ Setup ครบทั้ง 16 ภาษา โปรดระบุรุ่น OBS ชนิดแหล่งเสียง ข้อความสถานะ ขั้นตอน และปัญหาเกิดในการบันทึกจริงหรือไม่ อย่าส่งรหัสผ่านหรือไฟล์บันทึกส่วนตัวหากยังไม่ได้ตกลงความจำเป็นในการแบ่งปัน เปลี่ยนภาษาในตั้งค่า OBS แล้วเริ่ม OBS ใหม่ จากนั้นเปิดไฟล์คู่มือของโลแคลเดียวกัน
